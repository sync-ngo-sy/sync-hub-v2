# Design System

The shared visual language of both portals: the design tokens and every component that
renders purely from props. Nothing in this context fetches data or knows the API exists.

## Language

**Token**:
A named CSS variable in the single global stylesheet that carries one visual decision —
a color, a radius, a type step. Components reference tokens, never raw values.
_Avoid_: Theme variable, style constant.

**Primitive**:
A component generated by the shadcn CLI and kept as generated — never hand-edited, never
linted by our rules. The vendored floor of the system.
_Avoid_: Base component, atom.

**Molecule**:
A hand-written shared component composed from Primitives and Tokens (a data table, a
stat card, an empty state). Owned, linted, and tested like any of our code.
_Avoid_: Widget, composite.

**Promotion**:
The move of a component from one portal's feature into the Design System, permitted only
when a second consumer appears. Until then the component stays where it was born.
_Avoid_: Extraction, hoisting.
