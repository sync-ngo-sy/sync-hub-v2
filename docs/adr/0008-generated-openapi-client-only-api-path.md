# The generated OpenAPI client is the only path to the API

Every frontend call to the backend goes through `@sync/api-client` — types generated by
`openapi-typescript` from the live `openapi.json`, requests through `openapi-fetch`,
React Query hooks through `openapi-react-query`, and test handlers typed by
`openapi-msw`. No hand-written request/response types, no Zod validation of responses,
no ad-hoc `fetch` anywhere. The point is a single correctness guarantee: a backend
schema change breaks frontend compilation (and the test suite) at the exact call sites
that are now wrong, instead of failing at runtime. Rejected alternatives: hand-rolled
query hooks (query-key and type discipline left to convention) and Zod-parsing responses
(duplicates the schema and can only disagree with it). Cross-cutting request concerns —
cookie credentials, the `X-Sync-Request` CSRF header, the 401 → refresh → retry-once
dance — live in this package's middleware so the apps never reimplement them.
