Theme

The agreed system: Geist, one family. Status as a dot and a label — no pill, no fill. The panel colour promoted to a token, --deep, carrying weight in five places. Warm paper canvas and cards, so nothing on the page is white except the inside of an input. Everything renders at true size.

A four-step teal
--deep #104C44 surfaces · --primary #0F5C52 solid actions · --jewel #0F6E63 marks and charts · --accent-foreground #0F6E63 links and tinted text. Each step has one job, so nothing competes for the same element.
Dark theme, restored
Exactly as it was: warm graphite rail #171512, bright teal actions #23A092. The deep-teal panel is a light-theme device — at night the rail simply recedes instead of colouring.

Where the panel colour appears

Four places, all light-theme. Each is one line to pull back if it stops earning its keep.

1The railA coloured panel rather than an off-white one, at --deep #104C44. Still the deepest surface on the page.
2Primary buttons“New job” and “Sign in” sit one step above the rail at --primary #0F5C52. The rail recedes, the action advances.
3Sign-in crownThe auth card wears a deep band with the logo, so the first screen anyone sees is unmistakably branded.
4Stat tiles & focus ringsA small tinted square behind each figure’s icon, and every focused input rings in the brand. Low volume, high frequency.

Status

One green ramp plus two other hues, and shape doing work that colour cannot. New is a hollow ring — nothing has happened yet, so the mark is empty. In review is the one amber, because “this needs you” is the only state that should ever pull your eye. The four filled greens gain saturation along the pipeline rather than getting darker — Hired is the greenest mark on the row, not the blackest. Rejected and Withdrawn drop the mark for a circle-× in slate. Colour is never the only signal, and red stays reserved for irreversible buttons.
